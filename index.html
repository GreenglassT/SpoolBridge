What it does

Knows what's in each tray
Load a Bambu spool and its RFID tag is matched to the right spool in Spoolman. No typing.
Subtracts what you print
When a print finishes, the filament it used comes off that spool's remaining weight.
Handles third-party spools
Assign one to a tray in the dashboard and its filament settings are sent to the printer. Optional NFC tags in the OpenSpool format make it a tap.
Shows the printer live
Progress, temperatures, fans, AMS humidity, low-stock warnings, and a print history with success rate and estimated cost.
Stays on your network
It talks to the printer over its local MQTT connection. No cloud service in between.

Getting started

  1. Have Spoolman running somewhere on your network.
  2. On an always-on computer, clone SpoolBridge and install it: 
    git clone https://github.com/GreenglassT/SpoolBridge
cd SpoolBridge
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
python3 server.py
  3. Open http://<that-computer>:5555, go to Settings, and enter your printer's IP, serial number and LAN access code. They're all on the printer's touchscreen.
  4. Start the bridge, or install both as services so they run on boot. The setup guide has the details.

Questions

Do I need Developer Mode or the Bambu cloud?
No. On the P2S it connects with the LAN access code and doesn't need Developer Mode.
Will it work with my X1, P1 or A1?
It was built on a P2S with an AMS 2 Pro. Other Bambu printers send similar MQTT messages and may work, but they haven't been tested. Reports are welcome.
What does it change in Spoolman?
It adds a few extra fields, such as the RFID tag, and keeps each spool's location and remaining weight current. Everything else stays yours.
